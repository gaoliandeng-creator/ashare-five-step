# A股五步智能研究台 · 联网自动更新版

一个可部署的**静态网站 + Python 收盘数据生成器 + GitHub Actions 每日任务**。不用把数据API密钥放在浏览器里。数据失败时不生成虚构股票，原线上版本保持不变，但**上一日数据会过期**；网页上显示数据日期。

## 功能
- A股沪深京全市场行情快照，流动性初筛后限量扫描最多120只股票的历史K线（不是全市场全面覆盖）。
- 财务数据：东方财富业绩报表，营收与净利润同比增长；最新已到法定披露截止期的季报日期。没有数据就排除。上市新股、ST、高换手、明显弱势品种自动排除。
- 五步评分：大盘15分（同日市场上涨广度代理）；行业20分（如果快照提供行业，使用行业当日平均涨幅；否则中性50分）；基本面25；技术与量价30；风险与流动性10。
- 输出最多5只合格的观察候选。生成参考买入区间、技术结构失效价、2R/3R目标，以及基于28,000元账户、每笔1%风险预算、单只15%仓位上限的股数。
- 每工作日北京时间17:37自动运行（GitHub Actions UTC 09:37），通过GitHub Pages部署；支持手动运行。

## 在线部署（需您自己的GitHub仓库授权）
1. 登录 GitHub，新建一个**公开仓库**，如 `ashare-five-step`，将本 ZIP 中 `ashare_live` 文件夹内全部内容上传至仓库根目录，包含 `.github/workflows/daily.yml` 隐藏目录。
2. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
3. 仓库 Actions → `A-share post-close scan and GitHub Pages` → `Run workflow` 手动运行一次，查看日志是否成功。
4. 成功后在 Settings → Pages 取得站点网址：`https://<用户名>.github.io/<仓库名>/`。不要把这个格式当成已经部署的实际网址。
5. 工作日17:37（北京时间）会尝试获取当日数据并发布。节假日或数据校验失败时会跳过发布。GitHub定时任务可能延迟或失效，请检查 Actions 执行记录。

## 本地运行
Python 3.11+：
```bash
pip install -r requirements.txt
python src/run.py --preview
# 直接双击 site/index.html 可查看空白状态的完整UI
python src/run.py --account 28000 --max-scan 120
# 成功联网后，打开 site/index.html；也会生成 site/data/latest.json
python -m unittest discover -s tests -v
```

## 关键限制
1. 不是合规实盘荐股服务；没有自动下单。需要用券商行情、公告、合适的回测和成交模型独立验证。
2. GitHub Pages 是公开网页；不要写入您的持仓、个人信息或密钥。账户资金仅是示例参数，可以在网页上本地调节。
3. 只对成交额最高的至多120只（且基本面有数据）的股票做K线请求，**不是对5000多只股票进行完整排行**。流动性优先可能带来偏差。
4. 采用第三方AKShare公开页面接口，可能有访问限制、验证码、字段改变、网络失败。发生缺失或延迟时该日不发布新的报告。GitHub服务器访问东方财富也可能失败。
5. 财报按季报期取得，未逐条验证每家公司实际公告时间；因此不适用于任意历史日期回测，实盘前仍需核实最新公告。PE为行情来源的动态PE，与财务报告口径不完全一致。
6. 基于当前行情及复权K线计算参考点位；复权调整、低流动性、无涨跌幅限制的新股、ST、北交所特殊交易规则都需要进一步专项适配。特别是科创板最少买入200股。
7. 风险预算为理想成交条件下的估算，跳空、跌停或盘口不足时可能大幅超损；2R和3R是倍数目标，不是概率或保证收益。
8. 任务目前仅是部署配置，**没有创建用户的GitHub仓库、没有完成线上部署，也没有执行一次真实联网选股成功的验证**。请先测试数据源是否可用。

## 数据字段
`site/data/latest.json` 中 `status=ready` 时有 `as_of`、`report_period`、`candidates[]`。一日无合格标的时候选可能为空，绝不保证凑足5只。失败时直接退出，不覆盖之前发布内容。
